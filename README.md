# Design Skills

A curated collection of eight locally installed design skills.

- `banner-design`
- `brand`
- `design`
- `design-system`
- `hallmark`
- `slides`
- `ui-styling`
- `ui-ux-pro-max`

Copy the desired skill directory into your agent's skills directory. Each directory contains its own `SKILL.md`, references, and supporting resources.
